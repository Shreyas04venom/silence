┌──────────────────────────────────────────────────────────────┐
│ STEP 2: Deploy on Vercel (3 minutes)                        │
└──────────────────────────────────────────────────────────────┘

1. Go to: https://vercel.com/
2. Click "Add New Project"
3. Import your Git repository
4. Click "Deploy"

Vercel will automatically:
✅ Detect Next.js
✅ Use npm (not pnpm)
✅ Install with --legacy-peer-deps
✅ Build your app
